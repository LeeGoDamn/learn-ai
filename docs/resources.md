## 🎯 学习路径建议

::: info 初学者路径
1. 先学习 Python 基础和科学计算库
2. 完成吴恩达《机器学习》课程
3. 阅读《机器学习》（西瓜书）前几章
4. 参加 Kaggle 入门竞赛
:::

::: info 进阶路径
1. 学习《动手学深度学习》
2. 根据兴趣选择 CV 或 NLP 方向
3. 阅读经典论文，复现关键算法
4. 参与开源项目或实际业务
:::
