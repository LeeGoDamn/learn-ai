# AI入门学习教程

面向软件工程专业毕业生的中文人工智能入门学习教程网站。

## 📚 教程特点

- **目标人群明确**：专为具有编程基础的学习者设计，无需从零学习语法
- **循序渐进**：从前置知识到深度学习，由浅入深
- **理论实践结合**：每章配有代码示例和可视化演示
- **参考权威资源**：汇总吴恩达课程、李沐教程等业界顶尖资源

## 📖 教程大纲

### 第0章：前置知识
- [数学基础](chapters/prerequisites/math.html) - 线性代数、微积分、概率论
- [Python科学计算](chapters/prerequisites/python-scientific.html) - NumPy、Pandas、Matplotlib
- [数据处理基础](chapters/prerequisites/data-processing.html) - 数据预处理、特征工程

### 第1章：AI基础概念
- [什么是人工智能](chapters/basics/what-is-ai.html) - AI定义、历史与分类
- [机器学习概述](chapters/basics/ml-overview.html) - 监督学习、无监督学习、强化学习
- [开发环境搭建](chapters/basics/environment-setup.html) - Anaconda、Jupyter、GPU配置

### 第2章：机器学习入门
- [线性回归](chapters/machine-learning/linear-regression.html) - 模型原理、梯度下降、代码实现

### 第3章：深度学习入门
- [神经网络基础](chapters/deep-learning/neural-networks.html) - 感知机、激活函数、反向传播

### 第4章：实战项目
- [房价预测](chapters/projects/house-price.html) - 完整的回归任务流程

## 🚀 如何使用

1. 克隆仓库
```bash
git clone https://github.com/LeeGoDamn/learn-ai.git
```

2. 直接在浏览器中打开 `index.html` 即可开始学习

或者使用本地服务器：
```bash
# Python 3
python -m http.server 8000

# 然后访问 http://localhost:8000
```
